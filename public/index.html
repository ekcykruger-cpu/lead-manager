Reset all leads

Puts every lead back to its default state. Clears owners, call attempts, outcomes and one-time links. Sales employees and settings are kept.

Integration

Both scripts are started with the Admin API: POST /scripts/start.

No app password set. The server accepts any password. Set APP_PASSWORD on Railway before going live.

API endpoint

Every request sends skillId, scriptId, scriptPath and parameters (pipe-delimited) as JSON, with your bearer token.
